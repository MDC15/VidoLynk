# Palette's UX/Accessibility Journal

## 2025-05-14 - [Initial Assessment]
**Learning:** The application uses dynamic room lists and interactive elements that lack proper ARIA roles, keyboard navigation support, and visual focus indicators. Asynchronous actions like joining a room lack immediate feedback, which can lead to multiple clicks and user confusion.
**Action:** Implement keyboard accessibility for the room list, add ARIA roles to interactive elements, and provide visual feedback for the join button.
